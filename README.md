# Tales To Eternity

Tales To Eternity is a tabletop RPG system that seeks a balance between complexity and simplicity, so that everything works as well as possible. It also standardizes many rules and mechanics to make future content easier to create.

This repository holds the system's website: every book and database, with search, ready to use offline.

## What's inside

- **Books:** each book on its own page, with a table of contents.
- **Databases:** Races, Classes, Specializations, Skills, Languages, Items, Spells, Bestiary, Monster Abilities, Actions, Conditions, and Damage Types, with search and filters. Every term in the books links to its entry and shows a card on hover.
- **Bestiary:** every monster can be set to any Level (1 to 12) and Role (Minion, Standard, Elite, or Boss).
- **Encounter Builder:** build encounters for your group, add abilities to monsters, and see the points, difficulty, and XP.
- **Search:** search the whole site from the top bar.

## How to open

Open `index.html` in your browser. No internet or installation is needed. It also works with the Live Server extension in VS Code.

## Versions

The version number is **X.Y**: X goes up when a new book is released, and Y goes up with corrections. The changes are listed on the site's Versions page (`versions.html`).

Current version: **1.0**
